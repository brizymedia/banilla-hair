사진 올리고 공개하기

사진을 올리면 웹용으로 압축되어 저장되고, 홈페이지 갤러리에 모두에게 공개됩니다.

🔐 관리자 연결

처음 한 번만 GitHub 토큰을 등록하면, 이후에는 바로 업로드할 수 있어요.

토큰 발급 방법 (처음이신가요?)
이 홈페이지는 서버가 없어서, 사진을 저장하려면 GitHub 창고에 직접 넣습니다. 토큰은 그 창고 문을 열 출입증이에요. 이 기기에서 한 번만 등록하면 됩니다.
  1. 이 링크를 눌러 GitHub에 로그인하세요.
  2. Token name: 아무 이름이나 (예: 바닐라헤어 갤러리)
  3. Expiration: 원하는 기간 (1년을 권합니다)
  4. Repository access: Only select repositories 를 고르고 banilla-hair 하나만 선택
  5. Permissions → Repository permissions → Contents 를 Read and write 로 변경
  6. 맨 아래 Generate token 클릭 → 나온 토큰을 복사
  7. 위 칸에 붙여넣고 연결하기
왜 이렇게 하나요? 이 방식은 바닐라헤어 창고 하나만 열 수 있는 출입증입니다. 다른 방식(classic token)은 사장님의 모든 공개 창고를 열 수 있어서 위험합니다.
토큰은 사장님 기기에만 저장되고 사진 올리는 데만 쓰입니다. 기기를 남에게 넘기실 때는 연결 해제를 눌러 주세요.

끌어다 놓거나 눌러서 선택하세요. 자동으로 웹용 압축 후 저장됩니다.
