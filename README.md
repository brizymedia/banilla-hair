## 수정하는 법

이 저장소의 파일을 고치고 `main` 브랜치에 저장(푸시)하면
**1~2분 뒤 홈페이지에 자동 반영**됩니다. 별도 빌드나 설치는 필요 없습니다.

주요 파일:

- `index.html` — 메인 페이지
- `추천.html` — 스타일 추천 페이지
- `갤러리.html` — 갤러리 관리 페이지
- `CLAUDE.md` — 작업 시 참고할 프로젝트 규칙

## 기술

빌드 도구 없는 순수 HTML/CSS/JavaScript 정적 사이트이며 GitHub Pages로 호스팅됩니다.
